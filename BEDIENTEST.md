# Bedientest mit Referendarinnen und Referendaren

Ziel: herausfinden, wo Lehrkräfte ohne Hilfe hängen bleiben. Nicht die App
erklären, sondern zuschauen. Fünf Personen finden erfahrungsgemäß die meisten
Hürden.

## Rahmen

- Je Person 20–25 Minuten, einzeln, am eigenen iPad oder Tablet
  (TestFlight-Fassung, Einstellung *Werkzeuge: Einfach*)
- Vorher: App frisch installiert oder Daten gelöscht, damit der Startbildschirm
  erscheint
- Material vorab auf das Gerät legen (Dateien-App bzw. Downloads):
  - ein echtes Arbeitsblatt als PDF aus dem eigenen Unterricht
    (Ersatz: `test/vorlagen/libreoffice-blocksatz.pdf`)
  - ein eingescanntes Blatt (Ersatz: `test/vorlagen/scan-bruchrechnung.pdf`)
- Beobachtungsbogen (unten) ausgedruckt, Stoppuhr

## Einleitung (vorlesen)

> „Wir testen die App, nicht dich. Wenn etwas nicht klappt, liegt es an der
> App – genau das wollen wir finden. Sprich bitte laut aus, was du denkst und
> suchst. Ich helfe absichtlich nicht; wenn du nicht weiterkommst, sag es,
> dann gehen wir zur nächsten Aufgabe.“

## Aufgaben

Aufgaben einzeln vorlesen, nicht zeigen, wie es geht. Keine Fachbegriffe der
App nennen (nicht „Ebene“, „Auswählen“, „Mehr“).

1. **Blatt anpassen** – „Öffne das Arbeitsblatt. Ändere in Aufgabe 2 die Zahl
   in eine andere und lösche eine Aufgabe, die du nicht brauchst. Schick dir
   das fertige PDF selbst zu (oder speichere es in Dateien).“
2. **Ausfüllbar mit Lösung** – „Mach das Blatt so, dass Schüler die Ergebnisse
   am iPad eintragen können. Hinterlege für eine Aufgabe die richtige Lösung und
   erstelle zusätzlich ein Lösungsblatt.“
3. **Scan mit Hilfe** – „Öffne das eingescannte Blatt. Ändere ein Wort im
   Aufgabentext und füge eine Hilfe hinzu, die nur in einer Fassung für
   schwächere Schüler erscheint.“

Optional, wenn Zeit bleibt: „Leg ein neues Blatt mit Kästchen an und füge ein
Koordinatensystem ein.“

## Beobachtungsbogen (je Aufgabe)

| | Aufgabe 1 | Aufgabe 2 | Aufgabe 3 |
|---|---|---|---|
| Geschafft ohne Hilfe? (ja / mit Umweg / nein) | | | |
| Zeit (min) | | | |
| Erster Tipp – wohin? | | | |
| Wo gezögert oder falsch abgebogen? | | | |
| Wörtliche Äußerungen („Wo ist …?“) | | | |

Besonders darauf achten:

- Wird Text im PDF einfach angetippt – oder wird ein Werkzeug gesucht?
- Wird „Mehr“ gefunden, wenn ein Werkzeug fehlt?
- Wird der Umschalter *Arbeitsblatt / + Hilfen / + Lösung* verstanden?
  Landet die Hilfe in Aufgabe 3 wirklich auf der Hilfen-Ebene?
- Wird „Teilen“ bzw. „PDF exportieren“ gefunden, und ist klar, welche
  Fassungen angehakt werden?

## Nachgespräch (3 Fragen)

1. Was war am schwierigsten?
2. Was hast du gesucht und nicht gefunden?
3. Würdest du die App für deinen Unterricht nutzen – wofür zuerst?

## Auswertung

Hürden, die bei mindestens zwei Personen auftreten, kommen auf die ToDo-Liste –
vor neuen Funktionen.
